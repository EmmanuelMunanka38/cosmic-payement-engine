====================================================================
  SETUP
====================================================================

1. Start the server:
   npm run dev

2. Server should log: "Cosmic Payment started" on port 3000.

--------------------------------------------------------------------
  POSTMAN SETUP
--------------------------------------------------------------------

Create these variables in Postman (Collection → Variables):

  Variable          | Initial Value
  ------------------|---------------------
  base_url          | http://localhost:3000
  token             | (leave blank — filled by Login test)
  refresh_token     | (leave blank — filled by Login test)
  api_key           | (leave blank — filled by API Key creation)
  wallet_id         | (filled after wallet creation)
  txn_id            | (filled after transaction)
  user_id           | (filled after registration)

For the Authorization tab in Postman, select "Bearer Token"
and set the token value to {{token}} for protected endpoints.

For Idempotency-Key: generate a UUID per request in Postman
Pre-request Script:
  pm.variables.set("idem_key", pm.variables.replaceIn("{{$randomUUID}}"))
Then use {{idem_key}} in the header.

====================================================================
  2. AUTH — REGISTER
====================================================================

  POST  {{base_url}}/api/v1/auth/register
  Content-Type: application/json

  Body:
  {
    "email": "testuser@example.com",
    "phone": "+254712345678",
    "password": "password123",
    "firstName": "Test",
    "lastName": "User",
    "country": "KE"
  }

  Response 201:
  {
    "status": "success",
    "data": {
      "user": {
        "id": "user-uuid-here",
        "email": "testuser@example.com",
        "phone": "+254712345678",
        "firstName": "Test",
        "lastName": "User",
        "country": "KE",
        "role": "USER",
        "kycStatus": "UNVERIFIED",
        "isActive": true,
        "createdAt": "2026-05-27T00:00:00.000Z"
      },
      "accessToken": "eyJhbG...",
      "refreshToken": "eyJhbG..."
    }
  }

  ⚠️ Save the accessToken and refreshToken for subsequent requests.
  In Postman, set in Tests tab:
    var json = pm.response.json();
    pm.collectionVariables.set("token", json.data.accessToken);
    pm.collectionVariables.set("refresh_token", json.data.refreshToken);
    pm.collectionVariables.set("user_id", json.data.user.id);

  14. TRANSACTIONS — SEND (Internal)
====================================================================

  ⚠️ Requires: Idempotency-Key header
  ⚠️ Requires: Both sender and recipient must have wallets in
               the same currency. Recipient must exist.

  POST  {{base_url}}/api/v1/transactions/send
  Authorization: Bearer {{token}}
  Idempotency-Key: {{idem_key}}
  Content-Type: application/json

  Body:
  {
    "recipientEmail": "anotheruser@example.com",
    "amount": 50,
    "currency": "KES",
    "description": "Lunch money"
  }
  OR (use either recipientEmail or recipientPhone):
  {
    "recipientPhone": "+254712345679",
    "amount": 50,
    "currency": "KES"
  }

  Response 201:
  {
    "status": "success",
    "data": {
      "id": "txn-uuid",
      "reference": "TXN-...",
      "type": "SEND",
      "status": "SUCCESS",
      "sourceCurrency": "KES",
      "destinationCurrency": "KES",
      "sourceAmount": 50,
      "destinationAmount": 50,
      "description": "Lunch money",
      "createdAt": "...",
      "statusHistory": [ ... ]
    }
  }

  ⚠️ Save transaction ID:
    pm.collectionVariables.set("txn_id", json.data.id);

====================================================================
  ERROR RESPONSES (Common)
====================================================================

  All errors follow this structure:
  {
    "status": "error",
    "error": {
      "code": "ERROR_CODE",
      "message": "Human-readable message",
      "details": {}
    }
  }

  Common error codes:
  ──────────────────────────────────────────────────────────────
  400  MISSING_IDEMPOTENCY_KEY    Idempotency-Key header required
  400  VALIDATION_ERROR           Request body validation failed
  401  AUTH_TOKEN_MISSING         No Authorization header
  401  AUTH_TOKEN_EXPIRED         Token expired
  401  AUTH_TOKEN_INVALID         Bad token
  401  API_KEY_MISSING            No X-API-Key header
  401  API_KEY_INVALID            Bad API key
  401  API_KEY_EXPIRED            API key expired
  403  FORBIDDEN                  Not enough permissions
  404  NOT_FOUND                  Resource not found
  409  CONFLICT                   Idempotency key conflict
  429  RATE_LIMIT_EXCEEDED        Too many requests
  500  INTERNAL_ERROR             Unexpected server error
